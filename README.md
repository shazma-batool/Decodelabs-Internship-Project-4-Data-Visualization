# Decodelabs-Internship-Project-4-Data-Visualization

A data visualization project focused on transforming a cleaned e-commerce dataset into interactive charts and dashboards to uncover revenue trends, product performance, and operational insights.

## Project Overview

The project involved analyzing a cleaned dataset containing over 1,200 e-commerce orders. The main focus was on creating visual representations of key performance indicators (KPIs) to identify patterns in revenue generation, marketing effectiveness, and order status distribution.

## Objectives

- Analyze revenue distribution across product categories
- Evaluate the effectiveness of different referral sources
- Track revenue trends over time (monthly analysis)
- Assess order status percentages (cancelled, delivered, pending, returned, shipped)
- Create clear, readable visualizations for stakeholders
- Provide actionable business insights based on visual data

## Tools & Techniques

- Data Visualization Tools (Excel / Power BI / Tableau)
- Data Aggregation
- Trend Analysis
- Comparative Analysis
- Dashboard Design
- KPI Reporting

## Dataset Overview

The dataset used for this visualization is the "cleaned data" resulting from the previous project.

It contains 1,200 records covering the period from December 2022 to June 2025.

Key fields visualized include:

- Product
- Referral Source
- Order Date (Month/Year)
- Order Status
- Total Price (Revenue)

## Visualization Process

### 1. Revenue By Product

A bar chart was created to compare total revenue generated by each product category (Chair, Desk, Laptop, Monitor, Phone, Printer, Tablet). This helps in identifying top-performing and underperforming products.

### 2. Revenue by Referral Source

A bar chart was used to break down revenue based on the source of the customer (Email, Facebook, Google, Instagram, Referral). This evaluates the ROI of different marketing channels.

### 3. Revenue By Months

A line chart was constructed to show revenue fluctuations over time. This time-series analysis highlights seasonality, growth trends, and potential dips in sales performance.

### 4. Order Status Percentage

A pie chart was created to illustrate the distribution of order statuses. This provides insight into operational efficiency and customer satisfaction (e.g., return vs. delivery rates).

## Dashboard Structure

The visualization project contains four primary charts:

- **Revenue By Product** — Bar chart showing revenue per product category
- **Revenue by Referral Source** — Bar chart showing revenue per marketing channel
- **Revenue By Months** — Line chart showing revenue trends over time
- **Order Status Percentage** — Pie chart showing distribution of order statuses

## Key Outcome

The cleaned dataset was successfully visualized to reveal critical business insights. The analysis identified Printers and Chairs as the top revenue-generating products, Instagram as the most effective referral source, and highlighted a significant cancellation rate (20.8%) that requires operational attention.

## Key Learning

This project provided practical experience in creating meaningful visualizations from raw data, identifying trends and outliers, and translating data into actionable business insights for decision-making.
